# 交互式个人简历网页

此模板包含一个现代风格、响应式且带有交互动效的个人简历网页。已包含以下文件：

- index.html — 主页
- styles.css — 样式表（变量化配色、响应式布局、动效）
- script.js — 控制滚动 reveal、导航切换与进度条

特点：
- 清晰的版块：关于、技能、经历、项目、联系方式
- 滚动 reveal 动画与技能进度柱动效
- 悬停反馈（卡片上移、按钮阴影等）
- 响应式适配（移动端导航切换）

如何使用：
1. 克隆仓库并在本地用静态服务器打开 index.html。
2. 替换 index.html 中的个人信息与链接（邮箱、GitHub、项目链接）。
3. 可将图片替换为 assets 目录下的真实头像或项目缩略图。

定制建议：
- 若需使用 React/Vue 等框架，可把布局拆成组件并沿用 CSS 与交互逻辑。
- 可加入更丰富的动画库（如 GSAP）或无障碍增强（aria 属性、表单回显等）。
